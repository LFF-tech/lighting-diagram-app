# Diagram app documentation

Use this folder for durable product and engineering decisions that belong beside the code.

Suggested documents:

- `architecture.md` — application, rendering, storage, and export decisions
- `data-model.md` — diagram, fixture, modifier, subject, and metadata schemas
- `editor-behavior.md` — canvas interactions, shortcuts, and accessibility
- `deployment.md` — environments and release process

Keep business source-of-truth documents in the Lighting for Film Drive; store implementation decisions here.
